# Unified15 object preview

Explicit `SMARTSITE_AI_REALTIME_EXPERIMENTAL_MODEL_PROFILE=unified-ppe-15` requires realtime observation consumer1.1.0, the exact unified15 class map and YOLO11s artifact family before provider allocation. The default remains the legacy profile. This is source capability, not model adoption or accuracy approval.

Raw modelObjects are separate from wearer detections and business alerts. Projected objects carry artifactId/SHA and exact detection taxonomy, with no Worker/track/wearing state added. Camera/stream/session/sequence/capture time/frame dimensions must match the JPEG envelope. Empty object detections never mean compliance or missing PPE. Mask/Harness/Hook remain objects and do not add violation types.

Backend canonical preview parser accepts this optional object payload. Test fixtures cover all15 taxonomy entries, same-frame mismatch rejection and default/consumer compatibility.
