# Model artifacts

Không commit trọng số. Khi chọn model, ghi nguồn, version, checksum, điều kiện sử dụng, cách tải vào môi trường runtime và tập đánh giá tương ứng. YOLO26 là hướng detector đã chọn; chưa chọn/tải checkpoint PPE được kiểm chứng. InsightFace là ứng viên identity, chưa chọn model/enrollment store. Optional vision dependency không tự bật inference và API startup không tải model.
