# Model artifacts

Không commit trọng số. Khi chọn model, ghi nguồn, version, checksum, điều kiện sử dụng, cách tải vào môi trường runtime và tập đánh giá tương ứng. YOLO11s là baseline detector đã chốt cho MF05/MF06; chưa chọn, huấn luyện hoặc tải checkpoint PPE được kiểm chứng. RF-DETR Nano/Small và YOLO26s chỉ là đối chứng benchmark tùy chọn. InsightFace là ứng viên identity, chưa chọn model/enrollment store. Optional vision dependency không tự bật inference và API startup không tải model. Artifact Ultralytics mặc định chịu AGPL-3.0; phải rà giấy phép trước khi phát hành dạng đóng hoặc thương mại.
