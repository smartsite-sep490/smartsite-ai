# Runtime AI

`smartsite_ai` contains the FastAPI app factory, process configuration, contract models and hashing, Backend ingestion client, the OpenCV local-video/RTSP source, and the `smartsite-ai` entrypoint. The technical MF05/MF06 pipeline modules now provide deterministic tracking, PPE-to-person association, restricted-zone entry observations, and synthetic-input tests. Production camera/model inference, worker wiring, identity, and event production remain separate runtime milestones.
